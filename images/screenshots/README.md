# Screenshots Directory

Place real-time monitoring dashboard screenshots and physical breadboard test photos in this folder.

Recommended screenshots:
- `dashboard_normal.png`: Dashboard showing normal cruising status with stable 1g acceleration.
- `dashboard_accident.png`: Dashboard displaying active collision alert, high-G red graph spike, and Google Maps pin.
- `hardware_prototype.png`: Assembled ESP32 breadboard circuit with MPU6050 and NEO-6M GPS.
